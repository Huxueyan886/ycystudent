# 辽宁专升本 · 个人学习站

给大二专科生准备的个人专升本备考工具站（纯静态网页，无需后端）。

## 功能

- 顶部考试倒计时（可自定义考试日期）
- 科目看板：外语 / 计算机 / 高数·思政 / 专业综合课 / 技能考核
- 每日任务清单、错题本、学习日志
- AI 提示词库（一键复制）
- 智能规划：基础+状态打卡+每日小测，自动降难度生成今日推荐
- 高效资料库：高数/英语/计算机高频考点（含例题），可搜索、折叠、一键复制

## 使用

双击 `index.html` 即可打开，所有数据自动保存在浏览器 localStorage（`lnzsb_` 前缀）。

提示：资料为高频汇总，具体请以辽宁省最新考试大纲为准。
